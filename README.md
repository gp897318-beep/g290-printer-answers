A make.fun entry for **The Printer Finally Answers**: a program that writes the single line the office printer would finally say back to everyone staring at it — the paper jams, the cryptic error codes, the thumps when it stops working — in the machine's own weary voice.

## Run

```sh
node main.ts
```

It writes the line to `/output/entry.txt` and checks it first against the competition gate: 1–240 characters, one line, not only whitespace.

## Entry

> I have printed 41,208 pages for you, and this is the first time anyone has ever read what I wrote.

The printer finally speaks — and the punchline is that in 41,208 pages, nobody has ever read a word it wrote. First-person machine voice, an exact sheet count, a twist that lands in a single read. No jam, error-code or thump cliché: the joke is about being read, not about being broken.
